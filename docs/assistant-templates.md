# 助理模板

从侧栏打开 **助理模板**。内置知识问答、写作、代码和资料研究模板只读；复制后可以修改。自定义模板最多 50 个，支持新建、编辑、复制和确认删除。

模板保存名称、简介、助理指令、可选的聊天模型绑定、允许的工具、知识集合、长期记忆开关及检索策略。未绑定模型时跟随会话模型。绑定模型必须在“我的模型”的聊天模型列表内；移除模型后必须修正模板或解除会话模板才能继续调用。模板不提供文件夹权限，不绕过工具审批、模型允许列表或运行预算。

**使用模板新建会话**会把配置复制为持久化会话快照。聊天标题区域也可给已有会话应用模板。应用同时设置知识集合和记忆开关，并清除历史压缩缓存；原始消息不变。工具列表为空时禁用工具，自动工具和带 `chatId` 的手动工具调用都由服务端校验。没有模板的会话保留原有行为。

修改或删除模板不改变已有会话。标题显示所用快照版本；有新版时，点击 **更新为最新模板**才采用新版。已经开始的请求使用开始时取得的模型、指令、工具、集合与记忆策略，新配置作用于下一次请求。会话内可以单独覆盖集合或记忆开关；再次应用模板会重置为模板值。移除模板保留当前集合和记忆开关，恢复默认指令、工具范围和检索策略。

检索策略设置语义阈值（0.1–0.95）、最多来源数（1–8）及证据片段字符预算（1200–9600）。默认是 0.35、8 和 8000。阈值只过滤向量召回；关键词匹配仍可返回。预算仅统计片段正文，不包含提示词和引用元数据，不能代替模型的 token 上限。完整片段被选择或舍弃，引用不会指向裁剪后的人造原文。提高阈值或缩小预算可能遗漏必要证据，应使用知识库评测检查。

## 本地 API

- `GET /api/assistants`：内置和自定义模板，字段 `id`、`revision`、`builtin`、`config`。
- `POST /api/assistants`：提交配置，创建自定义模板。模型为 `{providerId, modelId}` 或 `null`；`tools` 必填且不允许重复；其余字段与上述配置对应。
- `PATCH /api/assistants/:id`：`{revision, config}`。版本不匹配返回 409，防止覆盖其他编辑。
- `DELETE /api/assistants/:id?confirm=true&revision=1`：无请求体，确认删除指定版本。内置模板不可删除。
- `POST /api/conversations`：可带 `assistantTemplateId`。相同会话 ID 重复创建不会覆盖快照。
- `PATCH /api/conversations/:id`：`{assistantTemplateId}` 应用最新配置，`null` 移除；不要在同一请求混合模板和集合/记忆覆盖。

模板写操作限 30 次/分钟，所有接口使用既有本地凭证、Host/Origin 和恢复互斥规则。会话列表和详情返回 `assistantConfig`，旧会话为 `null`。模板绑定模型拒绝客户端传入不同模型。

新增 SQLite 迁移保留旧会话和资料，首次升级由桌面迁移器创建数据库安全副本。便携备份包含自定义模板及所有会话快照，恢复会映射模板身份；已删除模板的快照也保留。旧备份默认无模板。新备份需要当前或更高版本恢复。原有文件夹授权仍会在恢复时撤销。无需新增环境变量或依赖。

验收可复制内置模板，设置集合与工具，创建会话；修改模板后检查旧快照未变，主动更新，再删除模板及重启服务，确认会话仍保留快照。工具限制、恢复和迁移由自动测试覆盖，真实模型回答质量另行通过 [知识检索评测](document-knowledge.md) 核对。
